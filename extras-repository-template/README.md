# Kumori Extras

The public, owner-curated Extras catalog for
[Kumori](https://github.com/Lorenso0/Kumori).

Catalog metadata and publication history are tracked here. Complete immutable
`.kextra` packages and their previews are stored inside two large, deterministic
GitHub Release bundle assets. Kumori verifies the signed complete catalog, each
bundle SHA-256, every contained package SHA-256, manifest inventory, and every
internal file hash before installing anything.

This repository is generated by Kumori's `scripts/publish-skins.ps1` workflow.
Catalog pull requests are welcome for review, but packages are published only
from the owner's verified local Extras library.
